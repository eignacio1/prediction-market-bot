## Four amendments to write into HYP-010 before Block E fits anything

Each is a forking path if it is decided after the result is known.

1. **Benchmark timepoint.** Measured 2026-08-24: median lead time from the last pregame snapshot to first pitch is **20 minutes** (p10 5 min, p90 13.5 h). HYP-010 never says which pregame price the model competes against, and the archive supports both. Closing is the sharpest price in the market and the hardest available benchmark; an opening-line variant is legitimate and materially easier. **Name one.**
2. **Pregame filter, asserted in the harness.** Game start = `close_time − 72h` (verified exact on 5,000/5,000 rows against the ticker's own date + `hhmm` read as ET). **21% of archive rows belonging to resolved events (14,815 of 70,762) are timestamped at or after first pitch.** Scoring without `run_ts < start` leaks the outcome into the forecast. The harness must assert the filter and report the row count it drops.
3. **Independent unit is the game, not the (game, line) row.** 219 games vs 2,408 quotes. Finding 3 already says this for Brier; say it for the EV gate too, or `n*` is inflated ~12×.
4. **Revised prior, stated up front.** Measured reliability is ≈0 (see §Standing findings) — there is no recalibration edge on this market. A team-level rolling model must win on *resolution* against a market already pricing starting pitcher, park, weather and lineup, none of which are model inputs. Expect the bottom of the pre-registered +0.005…+0.025 band or below. **Under Option A that is a finding, not a failure** — but it must be predicted before the run, not explained after.
