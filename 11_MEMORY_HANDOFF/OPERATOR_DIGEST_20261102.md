
## W97.4 - NHL engine (DEPTH)
Hockey now has one model that prices the whole board (moneyline, puck line, totals, team totals) from a single simulated score, so the prices agree with each other. On past seasons it beats a plain base-rate guess on moneyline and team totals. Against this season's Kalshi prices it is slightly behind (33 games, too few to be conclusive), so no forward test was started. Nothing was installed and no money is at risk. Re-check once about 200 games with Kalshi quotes exist.
