PROJECT DIRECTORY TEMPLATE — Archetype: Model Risk + Infrastructure + Research + Code Execution
Version: 1.0 (dynamically-agnostic; module-based)
Last updated: YYYY-MM-DD

HOW TO USE (Operating Rules)
- Canonical index: 11_MEMORY_HANDOFF/MEMORY_BANK.md is the “source of truth index” (it points to the current canonical artifacts).
- Traceability invariant: Requirements -> Design -> Implementation -> Tests -> Validation Evidence -> Approvals/Decisions.
- Reproducibility invariant: Every result must be re-runnable with pinned code + pinned environment + referenced data snapshot IDs.
- Decision hygiene: Major changes require an ADR (03_DECISIONS/DECISION_LOG/).
- Staleness control: Every artifact has Last Reviewed / Next Review + explicit “staleness triggers.”
- Archive policy: Move stale/superseded artifacts to ARCHIVE/ with a short rationale and pointers to replacements.
