# /retrain — Model Retrain Protocol

**STOP.** Before retraining, answer all of the following. Do not proceed until operator confirms each.

---

## Pre-Retrain Gate

1. **Why retrain?** — Model must be >30 days old OR Brier score drift > L2 threshold OR new seasons of data available. State the reason.

2. **ADR required?** — Any change to model class, feature set, or training procedure requires a superseding ADR (immutable policy, ADR-0004). Feature additions only (same class) = new FEATURE_VERSION is sufficient.

3. **New snapshot registered?** — New training data requires a new SNAP-YYYY-MM-DD-NNN registered in `DATA_SNAPSHOTS_INDEX.md` before training begins.

4. **Current model version?** — Read `models/prod_model_meta.json`. Record current `model_version` as the baseline to supersede.

---

## Retrain Steps

### 1. Data Refresh

```bash
# Pull latest game logs (may take 3-5 min; 0.6s throttle per player)
PYTHONPATH=src python3.11 src/prediction_market_bot/run_exp005.py \
    --output-dir exp_output/RETRAIN_$(date +%Y%m%d)

# Register new snapshot in DATA_SNAPSHOTS_INDEX.md before continuing
```

### 2. Run Experiment

```bash
# Treat retraining as a new experiment — use /new-exp protocol
# Assign next EXP-NNN ID
# Confirm metrics improve or are within acceptable range vs current model
```

### 3. Train and Save

```bash
PYTHONPATH=src python3.11 src/prediction_market_bot/train_and_save_model.py \
    --feature-csv exp_output/EXP-NNN/EXP-NNN_feature_matrix.csv \
    --output-model models/prod_model.joblib \
    --output-meta models/prod_model_meta.json
```

### 4. Validate New Model

```bash
# Confirm new model version hash differs from old
python3.11 -c "
import json
m = json.load(open('models/prod_model_meta.json'))
print(f'New model: {m[\"model_version\"]} | Features: {m[\"feature_count\"]}')
"

# Run full test suite — must stay green
python -m pytest tests/ -q
```

### 5. Compare to Baseline

Report:
- Old model version vs new
- Brier delta (new - old on same validation set)
- ECE delta
- Feature count change (if any)

**Decision rule:** Deploy only if Brier improvement ≥ 0.001 OR ECE improvement ≥ 0.005 OR data is >60 days stale. Otherwise keep current model.

### 6. Deploy (if approved)

```bash

    root@157.230.91.33:/opt/prediction-market-bot/models/

# T3 (PIPE-06) automatically uses the new model on next cycle — it reads T1's
# pregame JSON output which is regenerated by the updated model. No changes needed
# to execution_bands.py unless the model class itself changes (new ADR required).
```
