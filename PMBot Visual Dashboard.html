What is proven

Claims that survived a pre-registered test or a direct measurement.
  • The MLB pre-game tree beats climatology by ΔBrier +0.0052 over 1,414 games (EXP-028).
  • The NFL QB-shrunk challenger beats the frozen model in backtest: +0.0027, 1,852 games, 6 of 7 seasons (64.1).
  • Fills are adversely selected on both demo books: settle − price −0.25 (T4) / −0.39 (T1) on fills vs +0.10 / +0.07 on non-fills.
  • Kalshi settlement books every resolved bet: 1,229 / 1,229 agree with the cross-check (59.2).

What is disproven

Claims a pre-registered test or measurement killed.
  • MLB pre-game model vs market — HARMFUL, CI excludes zero (EXP-029).
  • T4 latency thesis — NOT SUPPORTED at the current feature set (T-569).
  • T4M-PROJ paper P&L as trading evidence — 94.5% of rows never filled; real fills lose (GG-527).
  • NFL recalibration and early-season shrinkage — no improvement over frozen (61.3, 64.1).
  • "Player hits dark since 9-27" — a window premise; the logs said otherwise (63.1).

What is unknown

Not yet measured — not assumed either way.
  • Whether any shadow cell beats its market — 0 of 45 engine cells at judged n.
  • Whether cancel-after-60 s + book pricing stops the picking-off — needs ~550 fills per arm in 8 weeks.
  • Whether props are looser than game markets — NBA player points logs from 10-20 (65.1).
  • Whether injury-report QB data moves the NFL model — needs point-in-time snapshots never captured.

Standing rules

non-negotiable

Carried into every block prompt. Most were written the expensive way.

Capital & control

  • No real capital until G6. Demo venue only; kelly_fraction 0 on every band.
  • Never bypass a permission control. Record the refusal and hand back.
  • No sizing change without an ADR.
  • An authorization exists only as a dated line in the queue — a table row is not one.
  • The operator never runs plumbing.

Evidence

  • Pre-registration on main before a cell's first row.
  • No score read below judged n; never relabel a verdict after seeing results.
  • Execution counts real fills only (GG-527, GG-536).
  • Never manufacture a row, price or score to have something to measure.
  • Never recommend against a sport, band or family on one finding.

Operating

  • Purpose before work (Hard Rule 12): name the measure a block moves, report what moved.
  • Three MEDIUM blocks a wave; 60-minute target, 90-minute ceiling.
  • Merge ≠ deploy ≠ activation — fixed means the running process has it.
  • Check every premise against logs and data before building on it.
  • t4-mlb restarts only when its code changed and no game is live.
